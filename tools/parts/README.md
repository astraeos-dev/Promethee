# Pièces KiCad converties

Modèles de la [bibliothèque 3D de KiCad](https://gitlab.com/kicad/libraries/kicad-packages3D)
listés dans `tools/parts.yaml`, convertis de STEP en glTF par `tools/build_models.py` :
millimètres, axe Y vers le haut, centrés dans le plan horizontal, surface de la carte à Y = 0.
Seuls le format, l'unité et l'orientation sont modifiés. Licence : CC-BY-SA 4.0 avec l'exception
KiCad, voir [sheets/models/LICENSE.md](../../sheets/models/LICENSE.md).
