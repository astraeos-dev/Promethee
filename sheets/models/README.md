# Modèles 3D

Ces fichiers `.glb` sont convertis par `tools/build_models.py` à partir de la
[bibliothèque 3D de KiCad](https://gitlab.com/kicad/libraries/kicad-packages3D)
(révision indiquée dans `tools/models.yaml`). Ils restent sous licence
**CC-BY-SA 4.0**, avec l'exception KiCad : voir [LICENSE.md](LICENSE.md).
Seuls le format, l'unité (millimètre) et l'orientation ont été modifiés.

`index.json` donne les dimensions de chaque modèle (largeur, hauteur, profondeur en mm).
